Device checks for the iPad binder

Nothing is needed before implementation. These three checks come after the last phase merges and before the feature PR merges. They need a real iPad and an Apple Pencil, which CI does not have.

0 of 0 steps done

Before implementation

Nothing to do. You can run /implement straight away.

After implementation

Do these once the feature PR is open and its checks are green. Paste each check's result line into the PR's Manual verification section.

about 10 min

The feature branch is not tagged, so there is no TestFlight build of it. Build it from your Mac.
